## ✨ 这是什么

一套给**不懂代码的产品经理 / 学生**的开箱工具包。把它交给一个能操作你电脑的编码 AI（Claude Code、Cursor、Codex 等），贴一句启动句，AI 就带你从"一个想法"走到"上线产品"——写代码、跑测试、做界面、部署上线，全由 AI 完成；你只做少量"必须本人才能做"的事。

## 🎯 它解决什么问题

| 你的处境 | 这个工具包给什么 |
| --- | --- |
| 有产品想法，但不会写代码 | AI 替你写全部代码，你只做业务判断 |
| 网上教程太技术、太碎片 | 内置三份技术手册，AI 按阶段自动读取 |
| 不知道"做到哪算好" | 每个阶段有明确闸门和证据包，你能自己核对 |
| 卡在云平台、密钥、备案 | 上线阶段有"照着点"清单，注册/认证/开权限都有引导 |

## 🚀 快速开始（约 1 分钟）

1. 把整个文件夹放到你电脑上（压缩包先解压，**不要改里面文件**）。
2. 用一个**能读写文件、执行命令的编码 AI 工具**打开这个文件夹（网页版纯聊天 AI 不行）。
3. 在对话框贴这句话：

   ```text
   请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。
   ```

4. AI 会根据你的情况自动走流程（有没有 PRD、是不是接着上次做）。之后每一步 AI 都会告诉你"下一步做什么"；看不懂就说"用产品语言再说一遍"。

> 📖 完整操作手册见 [开始看这里.md](./开始看这里.md)。

## 🧭 六个阶段

| 阶段 | 内容 | 你要做的 | 通过条件 |
| --- | --- | --- | --- |
| 0 PRD 体检 | 检查 / 补全产品需求 | 回答问题（≤5 个/轮，可回"按推荐"） | 补全清单全部关闭 |
| 1 技术适配 | 定技术方案 | 确认理解对不对、有无多出费用/范围 | 决策台账无影响本阶段的待定项 |
| 2 后端 MVP | 核心能力 + 真实验证 | 提供 Key、给真实结果打分、照清单验收 | 证据包已交 + 闸门全"是" |
| 3 正式前端 | 界面 + 移动端 | 给视觉方向、看代表页、真机走一遍 | 同上 |
| 4 上线 | 部署到云 | 注册/认证、控制台照着点、验收 | 验收清单全过 |
| 5 收尾 | 整理 + 删密钥 | 删云密钥 | 状态文件记录完成 |

每个阶段结束，AI 必须交**证据包**（截图 + 可打开地址/照着点步骤 + 是否表）。是否表有"否"就不能说完成。

## 🔒 内置的强制底线

这套规则卡约束 AI，你可以放心：

- 🔑 密钥不进仓库、不进前端、不回显
- 💾 数据可恢复，重启不丢
- ✅ 真实模型验证，不拿 mock 结果冒充
- 💰 涉及花钱的云资源，先告知费用再动手
- 🔐 用户只能看自己的数据
- 🛡️ 错误不泄露技术堆栈

## ❓ 常见问题

**要花钱吗？** 两处：模型 Key（按用量付费，AI 会帮你估）；上线云费用（上线前会估，创建前必须经你确认）。开发期可先不买 Key，AI 用模拟数据推进。

**必须企业认证吗？** 正式上线的默认方案需要云平台企业认证。没有的话，AI 先用临时方案上线并明确三条限制，认证办好后再切换。

**AI 说做完了，我怎么信？** 看证据包：截图 + 可打开的地址 + 是否表。有"否"就不算完成。

**可以中途换模型 / 换工具吗？** 可以。规则和进度都存在文件夹里（`docs/项目状态.md`），不依赖某个模型的内存。

## 当前银行客服演示（2026-10-02）

已经实现本机个人与企业文字咨询、演示来源、无依据处理、查询和人工未接入提示、敏感输入区分及 7 天会话保存。V1.2 修订增加公开对象分项、有限主题追问/澄清、可恢复的紧急提示与明确关闭、旧响应及后端主题版本保护。仅使用演示知识，不代表某银行已审核或接入。模型与云端付费调用均为 0，真实模型及产品经理体验验收待验，阶段 2 尚未完成。

### 产品经理启动与核对

1. 在 Finder 打开本项目文件夹，双击 `启动演示.command`。终端显示启动完成且没有报错时，保持该窗口打开。
2. 在浏览器输入 `http://127.0.0.1:18763`。看到“规则演示 · 非真实模型 · 模型验证待验”即为当前模式。
3. 首次进入先选择个人服务，发送“开户需要什么材料”，查看个人演示来源，再问“那需要什么”。新建会话问同样追问，应要求澄清。问“个人贷款和企业融资都要哪些材料”，应分别标明对象和来源。
4. 问“忘记密码怎么办”“验证码收不到”“2026年资料哪里查”，不应被当作凭证披露；仅用虚构测试输入“验证码是123456”检查屏蔽，不输入真实客户资料。
5. 发送“查余额”“转人工”核对未接入。发送“银行卡被盗刷了”，紧急提示应在普通咨询、切换企业和刷新后持续显示；点击“关闭此提示”，应说明未确认风险解除。刷新不复活旧提示，新的紧急输入再次激活。
6. 结束演示时点击启动时的终端窗口，按 Control+C，看到服务退出即可。重启后可恢复未过期会话主题及允许的提示状态。

已实际运行过服务与页面验收。交付时临时服务会停止，需按上述步骤重新启动。8000 与 8765 端口已被其他程序占用，项目使用 18763；若之后该端口被其他程序占用，告诉 AI 报错，由 AI 检查并调整，不关闭其他程序。

### 开发者启动与验证

在项目根目录执行：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
MODEL_MODE=demo .venv/bin/uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 18763 --no-access-log
```

验证命令在另一个终端执行：

```sh
.venv/bin/pytest -c backend/pyproject.toml backend/tests -q
.venv/bin/mypy --config-file backend/pyproject.toml backend/app backend/alembic backend/scripts
.venv/bin/ruff check backend
node --check backend/app/static/app.js
node --check backend/scripts/verify_browser.mjs
.venv/bin/python -m compileall -q backend/app backend/alembic backend/scripts
.venv/bin/python backend/scripts/verify_restart.py
```

自动化测试使用 mock，不发出真实模型请求。V1.2 实测 96/96 通过，保留原有 54 条并新增 42 条。真实进程恢复脚本使用独立临时数据库，验证主题、激活/关闭提示的多次停止与重启恢复，以及到期清理，不修改页面演示数据。测试客户端仍有一条 Starlette 提示未来迁移至 httpx2 的弃用警告，当前锁定组合通过，警告未屏蔽。

已安装 ego-browser 时，可对一个绑定在 18763 的**独立测试数据库服务**执行浏览器验证：

```sh
MODEL_MODE=demo DATABASE_URL=sqlite:///data/browser-check.sqlite3 .venv/bin/uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 18763 --no-access-log
```

保持该终端打开，在另一个终端执行：

```sh
.venv/bin/python backend/scripts/run_browser_check.py
```

脚本用有限的虚构问题新建测试会话，检查 1440/390 宽度并保存截图，完成后关闭本次浏览器任务；它不停止启动服务的终端。迟到测试只延迟真实演示接口响应在页面中的交付，不伪造模型或银行返回。运行中断后用脚本打印的空间编号加 `--space 编号` 续用同一任务，不另建任务。脚本由 Python 向浏览器隔离运行时传入项目路径，无密钥或凭证参数。

接口定义可在 `/openapi.json` 查看；健康接口为 `/api/v1/health`。业务错误统一返回 `{"error":{"code":"...","message":"..."}}`。当前短问答使用普通 JSON 响应，没有 SSE 或文件上传。

### 配置与数据

- Python 使用 3.12.14，依赖实测版本锁定于 `backend/requirements.txt`。
- 默认数据库为 `data/bank-demo.sqlite3`；启动时自动应用 Alembic 迁移。0002 仅追加主题/版本字段及紧急提示表，已在独立 0001 数据库验证历史保留。本轮开发测试没有修改原数据库。启动时和每小时清理到期记录，7 天从会话创建开始计算，不因访问延长；紧急状态不超出触发会话原定到期时间。
- `.env.example` 是无密钥配置示例；`.env`、`data/`、`.venv/` 与工具缓存已排除 Git。不把真实密钥发到聊天或放入前端。
- 本轮启动脚本强制 `MODEL_MODE=demo`。未来启用 model 前先确认厂商、模型、费用上限与数据流，再按指导填写后端配置。适配器只允许返回候选知识编号，最多尝试 2 次，超时/失败/无效输出都降级，不执行银行工具。
- 浏览器使用 HttpOnly、SameSite=Strict Cookie 的本机归属凭证，会话接口校验归属；这不等于银行认证，也不构成正式上线的多用户身份验收。
- 当前知识仅 6 条演示材料，有类型、状态、生效时间及版本。受控规则区分对象、有限主题追问及歧义，无法确认时澄清或拒答；正常年份/期限/金额讨论不一律屏蔽，凭证/卡号/联系信息测试仍拦截。该有限规则不保证通用语义理解或生产隐私保护；当前禁止输入真实客户、账户及企业资料。
- 新增 `/api/v1/safety` 和 `/api/v1/safety/dismiss`（关闭请求含 `expected_revision`）。主题并发冲突返回 409 `CONTEXT_CHANGED`，旧提示关闭请求返回 409 `SAFETY_CHANGED`；请刷新核对后再操作。紧急输入优先保存公开提示，仍需通过归属和到期检查。
- HTML、JS、CSS 为临时验收工具，没有正式前端打包或生产构建步骤；JS 已检查语法，桌面与移动端已实际核对。
