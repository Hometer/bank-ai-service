## ✨ 这是什么

一套给**不懂代码的产品经理 / 学生**的开箱工具包。把它交给一个能操作你电脑的编码 AI（Claude Code、Cursor、Codex 等），贴一句启动句，AI 就带你从"一个想法"走到"上线产品"——写代码、跑测试、做界面、部署上线，全由 AI 完成；你只做少量"必须本人才能做"的事。

## 🎯 它解决什么问题

| 你的处境 | 这个工具包给什么 |
| --- | --- |
| 有产品想法，但不会写代码 | AI 替你写全部代码，你只做业务判断 |
| 网上教程太技术、太碎片 | 内置三份技术手册，AI 按阶段自动读取 |
| 不知道"做到哪算好" | 每个阶段有明确闸门和证据包，你能自己核对 |
| 卡在云平台、密钥、备案 | 上线阶段有"照着点"清单，注册/认证/开权限都有引导 |

## 🚀 快速开始（约 1 分钟）

当前银行智能客服的 V1.5 本机体验入口是 **http://127.0.0.1:18769**。在本项目文件夹双击 **启动语音智能客服.command**，保持终端打开；原知识库入口 18768 及数据保留。已有 DeepSeek Key 只从后端 `.env` 读取，不需要重新发送。

选择个人/企业，输入非敏感问题后发送。系统优先使用知识库，必要时定向查已登记官网页面，使用 DeepSeek 摘录整理并附来源。推荐点击“本机语音提问”，阅读说明并同意，按浏览器提示允许麦克风；说完点击“结束录音并转写”（最长20秒），转写可修改后再发送。录音时可查看音量提示，新录音会替换未改动的旧转写，识别期间的手动修改会保留。浏览器语音入口保留，network错误时改用本机入口。勾选“自动播报”或点击“朗读上一条”，点击“停止当前回复”可打断。Mac 浏览器播报没有开始时使用免费系统普通话语音兜底，生成音频临时使用。人工辅助通过“准备人工参考”生成草稿，未连接/发送至真实坐席。

本轮单独批准最多新增1元/50次DeepSeek HTTP请求，含开发实测和重试；达到任一上限停止，旧18/20记录不重置。V1.5目前11次请求，保守费用估算0.01393元、预留0.2024元（不是平台账单）。完整721/721回归、类型/Lint/JS/编译与实际重启通过；真实模型、官网获取、实际系统音频播放及真实本机识别模型均已验证，物理麦克风识别、听感、真机与产品评分待后续验收。当前为普通话轮流对话和状态动效。

开发文档见 [V1.5 开发契约](../%E9%98%B6%E6%AE%B5%E6%96%87%E6%A1%A3/%E9%98%B6%E6%AE%B52-V1.5%E8%AF%AD%E9%9F%B3%E4%B8%8E%E8%81%94%E7%BD%91%E7%AD%94%E5%A4%8D.md)，截图、操作及阶段闸门见 [V1.5 证据](../evidence/%E9%98%B6%E6%AE%B52/2026-10-04-V1.5%E8%AF%AD%E9%9F%B3%E4%B8%8E%E8%81%94%E7%BD%91%E7%AD%94%E5%A4%8D/%E9%AA%8C%E6%94%B6%E8%AF%B4%E6%98%8E.md)。复核命令在项目根目录运行：`cd backend && ../.venv/bin/python -m pytest -q`；类型检查 `.venv/bin/mypy backend/app backend/scripts`，Lint `.venv/bin/ruff check backend`，页面 `node --check backend/app/static/v15.js`。浏览器脚本 `backend/scripts/verify_v15_ui.mjs` 必须在同一 ego-browser TaskSpace 中运行，包含付费真实调用，仅在本轮剩余额度内执行；ASR 部分为明确标记的模拟事件，不代表真实声音验证。费用台账只在明确批准时初始化，启动脚本不重置或自动新建额度。

1. 把整个文件夹放到你电脑上（压缩包先解压，**不要改里面文件**）。
2. 用一个**能读写文件、执行命令的编码 AI 工具**打开这个文件夹（网页版纯聊天 AI 不行）。
3. 在对话框贴这句话：

   ```text
   请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。
   ```

4. AI 会根据你的情况自动走流程（有没有 PRD、是不是接着上次做）。之后每一步 AI 都会告诉你"下一步做什么"；看不懂就说"用产品语言再说一遍"。

## 🧭 六个阶段

| 阶段 | 内容 | 你要做的 | 通过条件 |
| --- | --- | --- | --- |
| 0 PRD 体检 | 检查 / 补全产品需求 | 回答问题（≤5 个/轮，可回"按推荐"） | 补全清单全部关闭 |
| 1 技术适配 | 定技术方案 | 确认理解对不对、有无多出费用/范围 | 决策台账无影响本阶段的待定项 |
| 2 后端 MVP | 核心能力 + 真实验证 | 提供 Key、给真实结果打分、照清单验收 | 证据包已交 + 闸门全"是" |
| 3 正式前端 | 界面 + 移动端 | 给视觉方向、看代表页、真机走一遍 | 同上 |
| 4 上线 | 部署到云 | 注册/认证、控制台照着点、验收 | 验收清单全过 |
| 5 收尾 | 整理 + 删密钥 | 删云密钥 | 状态文件记录完成 |

每个阶段结束，AI 必须交**证据包**（截图 + 可打开地址/照着点步骤 + 是否表）。是否表有"否"就不能说完成。

## 🔒 内置的强制底线

这套规则卡约束 AI，你可以放心：

- 🔑 密钥不进仓库、不进前端、不回显
- 💾 数据可恢复，重启不丢
- ✅ 真实模型验证，不拿 mock 结果冒充
- 💰 涉及花钱的云资源，先告知费用再动手
- 🔐 用户只能看自己的数据
- 🛡️ 错误不泄露技术堆栈

## ❓ 常见问题

**要花钱吗？** 两处：模型 Key（按用量付费，AI 会帮你估）；上线云费用（上线前会估，创建前必须经你确认）。开发期可先不买 Key，AI 用模拟数据推进。

**必须企业认证吗？** 正式上线的默认方案需要云平台企业认证。没有的话，AI 先用临时方案上线并明确三条限制，认证办好后再切换。

**AI 说做完了，我怎么信？** 看证据包：截图 + 可打开的地址 + 是否表。有"否"就不算完成。

**可以中途换模型 / 换工具吗？** 可以。规则和进度都存在文件夹里（`docs/项目状态.md`），不依赖某个模型的内存。
