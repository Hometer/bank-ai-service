# 配置说明

首先运行知识库演示，使用非敏感公开问题。`.env` 配置真实服务时需要自己的 `MODEL_API_KEY`、`MODEL_BASE_URL` 和 `MODEL_NAME`。V1.5 语音与联网答复还有独立费用台账、服务开关与本机识别依赖，按配置说明启用；仓库不包含旧授权额度或私人台账。

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| MODEL_MODE / MODEL_API_KEY / MODEL_BASE_URL / MODEL_NAME | 根目录 `.env` | demo 为演示；真实文本模型须配置并确认费用 |
| PUBLIC_KNOWLEDGE_ENABLED | 环境变量 | 1 启用仓库中的公开资料知识库 |
| V15_ENABLED / V15_BUDGET_PATH | 环境变量 | 语音与联网答复独立开关及费用台账 |
| LOCAL_ASR_ENABLED / LOCAL_ASR_MODEL / LOCAL_ASR_CLI | 环境变量 | 本机识别需 Whisper CLI、模型文件和 FFmpeg |

## 本机数据与验证

`backend/app/` 为 FastAPI 与静态网页，公开知识与来源存于 `docs/知识库/`。SQLite 会话、模型文件和预算台账在被忽略的 `data/`。

各项目端口可能重叠，分别运行时先停止自己启动的前一项目，或按各项目配置调整端口与代理。密钥、业务数据、模型文件、依赖和构建产物留在本机，不进入公开仓库。克隆仓库不会带入原电脑的模型配置、邀请码数据库或费用额度。

## 工程检查

以下为离线工程检查入口；历史真实模型脚本可能产生费用，请先阅读对应验收记录。

```bash
.venv/bin/python -m pytest backend/tests -q
.venv/bin/ruff check backend
.venv/bin/mypy backend/app backend/scripts
node --check backend/app/static/v15.js
```

本次 GitHub 整理不追加真实模型调用，也不改变产品阶段验收结论。历史开发过程见 [开发记录](历史/开发记录.md)。


## 东亚香港知识库配置

默认加载[东亚公开知识](知识库/东亚银行香港/README.md)，PUBLIC_KNOWLEDGE_PATH、PUBLIC_ACTIVATION_PATH、BANK_FAQ_PATH和BANK_FAQ_ACTIVATION_PATH分别指向本目录的public-base.json、public-activation.json、knowledge-base.json和activation.json。默认来源为东亚香港官网，未注明银行的咨询按东亚香港处理。

22条知识保留银行和地区、服务对象、官方URL、定位、读取日及复核期限。到期停止引用，不自动使用交银或其他地区的条款。历史来源测试按当时核对日期运行，当前东亚测试使用当前日期并包含到期、串行和跨地区防护。
