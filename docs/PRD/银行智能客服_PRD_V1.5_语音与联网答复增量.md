日期：2026-10-04。状态：范围准备，三个影响成本、音频数据流及人工承接的问题待确认；尚未开发或进行新增模型调用。

## 1. 目标与用户

个人及企业客户继续以交通银行（香港）有限公司为咨询主体。客户可以通过说话提问，获得有出处的文字及语音答复。DeepSeek 使用现有后端 Key，新增从资料组织答复的能力；同业资料仍只能作为明确标注的通用参考。

转人工相关需求分为人工辅助和实际接管。首轮推荐生成问题摘要、查询相关官网资料并准备参考答案，交人审核；真正银行坐席接管取决于平台、队列、授权及可信回执，不以“AI继续答复”冒充人工。

浏览器语音识别可能向浏览器服务发送原始音频，和“不在本项目保存原始音频”是两件事。首次开启前解释数据流并获得用户主动同意；产品经理确认演示数据边界后才启用。若要求纯本机识别，应先改选本机识别实现，不能静默回退到云端。

首轮普通话和轮流对话只是推荐，尚未获得确认。粤语、边说边打断的全双工通话、仿真人连续口型视频、实际坐席平台接入不能被默认视为已完成。

## 3. 回答流程

1. 沿用敏感信息、紧急问题、私有账户请求与人工请求的前置处理。
2. 获取同一客户类型、同一银行、仍有效的本地资料，并识别当前问题及必要的已验证上下文。
3. 完整命中时优先使用本地资料；部分缺口、时效问题或用户明确查官网时，再进行有上限的官方资料获取。
4. DeepSeek 只收到脱敏问题、必要上下文和受控资料片段，不收到密码、验证码、完整聊天历史或原始音频。
5. 结构校验、来源 ID 校验、引文匹配及银行实体校验通过后，返回正文与来源。没有证据的条件说明未知，不保证模型永不出错。
6. 保存最终答复、出处与处理状态；文字先可查看，再进行可打断的语音播放。

人工请求不被联网查询阻挡。没有真实承接时立即说明未连接；准备参考答案由用户选择。即使没有查到资料，也不能把“AI建议”展示为人工回执。

## 语音识别修订（2026-10-04，用户已授权）

用户实际使用时出现浏览器识别 network 错误。该错误发生于语音转文字，不能证明 DeepSeek 故障。用户同意增加本机识别兜底，本次为 V1.5 增量修复，不重写产品目标。

- 增加“本机识别”入口，保留浏览器识别。浏览器 network 错误只提示改用本机入口，不静默重新开启麦克风。
- 本机录音最长20秒，录音结束后在当前Mac运行 whisper.cpp small 多语言模型；只上传到本机后端，不发送音频给DeepSeek或语音云服务。录音临时处理、结束清理，不进入知识库、会话数据库或日志。
- 识别任务、脱敏转写和确认状态持久化，刷新恢复转写待确认；服务重启使未完成任务失败，不重放录音或自动启动付费答复。
- 显示转写，用户可修改后点击发送；停止、取消、切换客户使迟到结果失效。麦克风必须由用户主动授权。
- 免费本机软件与模型约466MB；沿用普通话轮流交流范围，不新增付费供应商或重置DeepSeek预算。
- 真实离线模型音频冒烟、接口与取消/归属/上传边界自动化、桌面与手机宽度分别验证；合成测试音频不能冒充真实麦克风测试，产品验收继续后置。

本机识别修订实施记录：716/716程序通过，实际本机模型与浏览器录音编码/待确认刷新/DeepSeek答复通过（输入为合成测试音频），物理麦克风待验；新增一次DeepSeek调用，新11/50，原18/20保留。保持普通话轮流范围与用户验收后置。
