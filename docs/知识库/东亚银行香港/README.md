# 东亚银行香港公开知识库

当前项目咨询主体为东亚银行有限公司香港业务。知识库包含22条官方公开咨询知识，覆盖个人开户、存款、贷款提示、企业开户、结单、融资、i-Token、转数快、API同意和保安事项。每条记录银行、服务对象、官网URL、定位、读取日期及复核期限。

默认启用本目录，交银及同业原资料保留为历史参考，不进入当前检索或联网答复。public-base.json关闭原交银产品目录，实际东亚知识由knowledge-base.json及activation.json加载。

7日或30日复核到期后停止引用。资料不属于银行内部知识库，也未获银行审核；当前实现提供公开咨询和语音播报，不接入真实账户、交易或坐席。银行项目历史成果与本地验证记录分别保存。
