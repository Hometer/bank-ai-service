# 交银香港知识库接入说明

2026-10-03。用户明确要求将资料连接产品并优先回答，已实现并验证本地知识优先链路。本包30条知识、19个来源、9项排除；公开整理未获银行审核。

## 运行方式

默认 `Settings.from_env()` 启用公开知识。知识源为本目录 `knowledge-base.json`，独立运行清单为 `backend/app/public_activation.json`，启用30个知识编号。候选包中的staged、enabled=false、bank_reviewed=false是归档属性，不冒充银行批准；实际是否可答还检查运行清单、实体、地区、完整来源核对状态和日期。

原六条 `backend/app/knowledge.json` 及 `service_catalog.json` 字节保留。运行时映射为个人5类/企业6类：原六类加双方借贷成本、双方存款保障、企业外汇远期。只返回适用知识正文和限制，模型不生成金融事实；启用知识库时不发出模型请求。歧义继续有限澄清，未知事项说明缺口。私有查询、敏感、紧急、人工等保护依旧优先。

## 接口和来源

保留原请求/响应字段，增加processing=knowledge、coverage=supported以及可选官网引用、知识条目编号、核对日期和内部复核日期。历史仍保留当时答复及来源，下一次动作重新核对版本/全包指纹；来源、正文、启用范围变化会使旧动作失效，提交前检查可阻止迟到答案落库。

完整开发契约与验证见 [阶段文档](../../阶段文档/阶段2-交银香港知识库接入.md)。八条实际接口答复及待填评分见 [样例](../../阶段文档/交银香港知识库本地答复与评分.md)，没有沿用旧版满意度。

## 核对与边界

先打开 `http://127.0.0.1:18768`，或在项目文件夹双击 `启动知识库演示.command`。选个人问“开户需要什么材料”，应说明遥距材料并有官方链接；再问“今天港元定存利率是多少”，应提示缺少报价依据。选企业问“企业对账单在哪里下载，需要什么权限”，应解释正式渠道及权限而非声称已查询/下载。该入口仅使用独立本地演示数据库。

S18已补核香港政府新闻完整页面及发布时间，来源不再停留在搜索摘录。企业开户分类附件、定存提前支取完整条款、部分最新优惠/方案细节仍未成功完整读取，保留资料缺口；排除项不进入可答库。贷款收费只适用于所引DreamCash产品，不套用按揭或税贷；八成公告期限不套用九成。

`review_due_on`为内部复核期限，日期当天停止引用，不是银行产品有效期。明确的生效/截止日期另行检查，未知日期保持null。复核需重新查官方来源、更新核对日期和依据后再启用，不自动延期。成员银行当前名录仍未核实，不出具某银行或个人的存款保障结论。

余额、明细、回单、转账、贷款审批等实际业务仍未接入；公开知识不授予认证或账户权限。
