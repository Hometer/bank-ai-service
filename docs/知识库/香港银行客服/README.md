# 香港银行客服知识补充包

已接入现有产品，共新增116条、22个官方页面；连同原交银香港30条，共146条。客户题目和入口以交银香港为主体；12条建议允许参考同业通用方法，具体银行条件不移植。同业具名查询与原资料保留。

- [交银主体客服手册](交银香港客服知识手册.md)：70条交银场景题目，含本行依据和明确标记的通用参考。
- [研究资料手册](知识手册.md)：覆盖表、官方出处、排除原因及116条可读答复。
- [结构化资料](knowledge-base.json) / [数据契约](knowledge-base.schema.json)：银行、对象、问题变体、检索规则、正文、限制、出处定位及复核日。
- [来源核对记录](source-verification.json)：核对日期和本地官方页面文本校验值，不包含整页转载。
- [校验脚本](校验资料.py)：运行 `.venv/bin/python docs/知识库/香港银行客服/校验资料.py`。
- 启用清单：`backend/app/bank_faq_activation.json`，从档案独立管理。

沿用根目录 `启动知识库演示.command`；`PUBLIC_KNOWLEDGE_ENABLED=1` 时默认启用，可用 `BANK_FAQ_ENABLED=0` 暂停新增FAQ。旧资料、旧演示和数据库保留。修改数据后重新校验并重启预览；生产服务和多用户访问未开放。

没有新增模型调用。敏感凭证、紧急风险、人工及私有查询仍走原保护链路。资料未获银行审核，不保证覆盖所有金融问题；及时复核官网变更，不自动续期。
