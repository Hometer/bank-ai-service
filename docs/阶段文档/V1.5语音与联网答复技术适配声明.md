## 1. 产品形态判断

继续阶段 2 的本机公开咨询纵向切片，在现有金融风格页面上同时验证语音、受控资料和模型答复。用户授权新能力开发方向，但实时程度、音频处理地点、人工承接和新预算需要落实。没有提前进入部署或生产银行接入。

## 2. 默认方案

- 复用 Python 3.12/FastAPI/Pydantic、原生 HTML/JS/CSS 和既有 SQLite 会话、归属校验、版本号及七天清理。
- DeepSeek 延续官方 `deepseek-flash` 非思考模式和现有后端 Key；增加资料驱动的生成契约，不替换旧路由接口或伪称旧系统已在生成答复。
- 推荐首轮浏览器语音识别与语音合成，保留文字；识别能力和数据流必须显式说明，不能将服务器识别称为纯本机处理。
- 形象状态/声波动效和真实识别/播放事件对应，首轮不引入视频供应商或仿真人嘴部动画。
- 后端使用官方来源注册表和受控 URL 做定向网页获取，避免新增搜索服务 Key。若覆盖不足，说明“官网定向检索”限制，进一步全网搜索另行确认服务和费用。

## 3. 按需模块

新增受控网页获取/文本提取、生成结构校验、独立本轮预算配置/台账、可恢复答复任务和语音控制器。只有确认实际人工接管时才引入真实坐席适配器；人工参考草稿不能充当接管回执。

## 4. 暂缓与影响

粤语/全双工/实时口型视频取决于 Q15-01，真实坐席取决于 Q15-02；新增付费调用取决于 Q15-03。所有既有功能及知识保留，不为本轮技术完整性更换框架、数据库或供应商。

## 5. 强制底线

Key 仅由后端读取；音频不落盘；转写先脱敏，所有外部请求有限、超时和可取消。任务、费用预留及最终出处持久化，服务重启不能重置额度。请求/响应/错误必须强校验，模型失败和网页失败各有真实状态。所有官方 URL、重定向、正文来源和银行实体核对；外部网页只是资料，不接受其工具执行指令。

原模型预算仅授权选择/路由合同，最多 20 次；已使用 18 次。新生成输出更长，不能直接修改原 POLICY 或借剩余两次执行新合同。

## 6. 费用与必要确认

推荐独立新增 1 元/50 次请求批准，旧记录原样保留。按官方当前 Flash 高峰价格输入 2 元/百万 tokens、输出 8 元/百万 tokens估算，单请求保守约束总输入最多 6000 tokens、输出最多 800 tokens，预留 0.0184 元；50 次预留 0.92 元。输入预算包含完整模板、资料和上下文，必须在请求前以可靠计量/更保守的字节上界落实，不能只按客户问题长度计算。价格变化须重新核对并冻结超预算请求，估算不冒充平台账单。

本轮不申请/创建付费云资源，不新增付费语音或搜索供应商，不充值。问题及推荐见 PRD 第 4 节。

## 7. 外部能力核验（2026-10-04）

- [DeepSeek Chat Completions](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)：现有聊天接口支持结构化文本、流式输出和 function 工具；这套接口文档未提供音频转写/合成，也不能据此认为一个 Key 自动具备浏览器联网能力。
- [DeepSeek Tool Calls](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/)：工具执行需要应用实现，后端提供检索资料再交模型组织答复。
- [官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：沿用 `deepseek-flash`；本页价格仅作为本次提案估算依据。
- [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)：兼容性受限，部分浏览器使用服务器识别；纯端侧支持必须单独探测，不能静默转云端。

本轮仅读代码和官方文档，尚未重新运行自动化测试、操作麦克风或调用真实模型。历史 649/649 不能写成 V1.5 验证结果。
