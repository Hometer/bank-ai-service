# 阶段2：交银香港知识库优先接入

日期：2026-10-03；开发前保存。用户明确要求“现在将知识库与产品连接起来，在回答客户问题时，优先调用知识库内容”。继承V1.4本机、隐私与业务权限边界。

## 目标和技术适配

现有问答优先读取已整理的公开知识；有适用内容时直接返回受控知识答复及限制，并展示官网来源、核对日和内部复核期限。问题包含无依据事项时逐项说明缺口。保持模型只作结构化路由，金融正文不交给模型自由生成。

沿用Python/FastAPI/Pydantic、原生验收页、SQLite和现有依赖。新增结构化资料加载及本地检索，不引入向量数据库、Embedding费用或新平台。原六条演示JSON和目录留作兼容基线；默认产品启用独立的公开知识接入配置。研究包保持原候选记录，运行配置单独记录用户授权启用的条目，公开搜集不表示银行审核。

## 契约与处理顺序

1. 原紧急、敏感、人工、私有查询及取消规则优先，公开知识不能赋予账户权限。混合问题仍按原公开／私有分项处理。
2. 按对象、地区、实体、启用配置、来源验证、时间检查资料；显式主题及有效多轮上下文先进行本地知识检索。支持原六类以及借贷成本、存款保障、企业外汇远期等明确补充主题。
3. 明确命中时使用知识内容，标记知识库处理，无需模型请求。歧义依旧有限澄清；未命中时保持有依据才答，不因缺少资料让模型编造。原演示模式可通过显式配置继续验证。
4. 知识正文同时带适用限制。贷款具体费率只适用所引DreamCash产品，不能套用按揭；企业简易账户限制不能套用所有企业账户。最新利率、未读附件、本人审批／交易结果继续明确缺口。
5. API保留原字段，添加公开知识状态、引用URL和资料标识等可选信息；旧历史可读。来源版本／正文／资料有效性变化时，沿用既有指纹失效规则，提交前再核对，不能保存已过期答案。
6. 对话及来源随原事务持久化。原用户数据、费用台账及模型参数不迁移、不重置。

## 验证与交付

运行原251条测试及知识接入专项（原24条资料验收落实为接口或规则断言），补充过期／停用／损坏／错误实体、未知事项、模型不可用但知识可答、多主题、明确纠正、并发来源变化、旧历史和实际进程重启恢复。运行mypy、Ruff和JS语法检查；桌面1440及390模拟宽度检查来源链接和答复。

本次知识正文为确定性本地链路，正常命中不调用模型；不动用原18/20台账剩余两次重试额度。真实模型新候选语义路由未新增验证时如实记待验，不能沿用旧十条评分代填新知识效果。纯知识链路与新模型候选覆盖分开记录。

交付新的知识演示启动入口和可核对的问答样例、README／状态／证据闸门。真实手机和正式银行服务继续待验，不宣布阶段2整体收口。
