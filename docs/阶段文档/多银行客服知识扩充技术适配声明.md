# 多银行客服知识扩充技术适配声明

2026-10-03，开发前落盘。用户明确要求从各大银行官网选取客服问答以完善当前知识库。沿用既有香港产品定位先核对香港主要银行；地区偏好问题已发出，收到新增地区要求时再按实体和地区单独组织。

## 范围与资料规则

保留现有30条交银香港知识，新增交银香港、汇丰香港、恒生、中银香港、渣打香港、东亚香港的官方常见问答及香港金管局通用知识。重点转数快、转账失败、电子结单、登录/重置、换手机、银行卡、客户资料和企业网银权限。逐条改写为简洁客服答复，不复制整页、营销语或第三方文章；保留银行、地区、对象、来源定位、核对日期、适用限制及内部复核日。未读取或无法核实的附件、旧通告冲突、其他地区规则不启用。

默认银行仍为交通银行（香港）有限公司；其他银行资料只在明确具名问题或该银行的有效会话上下文中使用。银行切换和主题纠正以当前问题为准；地区或银行不明时不套用其他规则。一般公共支付概念可引用香港金管局，必须标为地区通用知识，不作为某银行开户、费率、授权或金额承诺。

## 技术适配与费用

继续FastAPI/Pydantic、原生单页、SQLite及确定性本地检索；不迁移框架/依赖/用户数据，不引入向量云或新增模型契约。公开资料补充文件与独立启用清单分开，开启现有PUBLIC_KNOWLEDGE模式时默认加载补充资料；直接Settings构造保留旧测试行为。来源允许名单同时约束服务器及页面链接。不向模型提交问题，原费用policy/调用台账不变。

## 主链路与边界

问题→既有脱敏/紧急/人工/私有查询保护→识别银行/对象/FAQ意图→引用有效条目→附来源与缺口→持久化答复及银行/条目绑定→前端可查看。银行和资料切换、停用、复核到期或指纹变化时上下文失效；不能转成错误银行或过时事实。未知问题明确缺口，复合问题不丢弃未覆盖部分。公开密码重置说明可以回答，实际凭证依旧屏蔽，实际重置/退款/转账均不执行。

## 验证与交付

保留339条原自动化，新增逐条检索、银行/地区隔离、追问/明确切换/未知缺口、个人企业、受保护路径、停用/来源变更/到期和损坏配置测试；运行mypy/Ruff/语法、真实本地接口与进程重启、1440/390页面。来源核对使用一个ego-browser任务空间16与官方网页读取。交付结构化知识、可读手册、覆盖表、源码、README、项目状态、实际答复样例及截图/步骤/闸门。效果评分及真实手机不代填；本轮非模型知识链路不重复付费模型验证，不宣布完整正式银行或上线完成。

## 用户方向修订（实施前，2026-10-03）

用户反馈“回答倒是没有什么问题”，要求题目以交通银行（香港）为主体，答案可参考其他银行。记录为定性反馈，不代填数字评分。保留同业原始资料供溯源，增加交银主体的通用客服建议层：同业通用处理方法可参考，其他银行费率、额度、认证等待时间、产品条件、SWIFT及App品牌/菜单不得移植成交银事实；地区公共事实标明金管局通用依据。

新增 evidence_role 区分 bank_rule / peer_guidance / regional_guidance。参考条目只能面向交银、带固定说明及真实原发布者；服务器严格限制跨银行来源只用于已标记参考条目，原 bank_rule 归属校验不放宽。前台目录以交银与公共基础知识为主，已有具名同业查询及研究档案保留。示例与验收题改成交银香港，效果重新留待反馈。
