## 2. API 草案

下列路径尚不存在，命名及字段在开工时定稿。所有接口沿用同一会话归属及客户类型校验；错误统一为 `{"error":{"code":"...","message":"..."}}`。

| 路径 | 请求 | 响应/错误 |
| --- | --- | --- |
| GET /api/v1/capabilities | 无 | generation/web/voice/assistant 的启用状态及限制；无 Key 内容 |
| POST /api/v1/sessions/{sid}/answer-jobs | text、expected_revision、request_id、intent(answer/agent_assist) | job_id、pending、当前 revision；422 输入，404 归属，409 版本冲突，503 不可用 |
| GET /api/v1/sessions/{sid}/answer-jobs/{job_id} | 无 | pending/running/completed/failed/cancelled、revision、已校验结果；未完成不能包含未经校验的生成正文 |
| POST /api/v1/sessions/{sid}/answer-jobs/{job_id}/cancel | 无 | cancelled 或已经完成状态；取消后迟到模型响应不能覆盖新会话 |

推荐首轮任务+轮询，先不为“实时”词语强行流式输出未验证金融文字。轮询可以展示检索/思考状态；完整正文通过校验后立即展示和播报。若确认需要流式合同，再定义 `chunk`→`done` 或 `error` 的实际协议和实测，不能把最终文本拆字播放称为模型实时流式输出。

## 3. 新模型契约

输入包含脱敏问题、个人/企业对象、银行实体、已验证上下文和最多三段有效证据。实际模型输出严格结构为 `claims/unanswered`，正文与固定提示由后端确定性组装，每条 claim 绑定已提供的 source_id 及可匹配的短引文。未知 source_id、无资料条件、实体冲突、异常字段或不合法 JSON 直接校验失败。

来源与引文匹配不能证明全部自然语言推理正确；再对费率、期限、额度、业务状态等高风险条件做确定性限制，未覆盖内容回退为缺口或原文摘录。真实生成质量仍需专门样例测试。

模型 timeout、有限重试及客户端构造失败均统一兜底；50 次额度包括所有 HTTP 尝试。没有充分资料时可以直接不调用模型。模型失败时显示本地可核对资料，标明为本地降级。

## 4. 受控联网

- 从已经核验的官方网页/来源注册表按主题选择候选，每轮最多三页，总任务截止暂定 30 秒，抓取单页最多 5 秒，正文最多 1MB；具体阈值开工时覆盖测试。
- 只允许 HTTPS、443、无 URL 凭证；禁止 localhost、私有/保留 IP、任意用户 URL；核验 DNS 和每次重定向，最多两次且仍须官方域名与正确地区。
- 原始客户问题不投给第三方搜索引擎。官网获取只发送固定公开 URL；完整对话不进入 URL、headers 或日志。
- 过滤脚本/样式，优先香港有限公司资料，不混分行或海外地区。同业具体条件不用于交银事实；来源性质保留。
- 保存已使用的最少必要片段、来源标题/URL、抓取时间及校验摘要；网页更新与本地知识下架可使旧待播内容失效。联网片段不自动写入正式知识库。
- 无结果、页面变更、网页解析失败、内容注入或超时均有明确状态，不称已经“查到正确答案”。

## 5. 语音与动态状态

推荐状态 `idle/listening/transcribing/reviewing/thinking/speaking/error`，真正识别/播报回调驱动；页面刷新不自动开启麦克风或重播。每个识别轮次和播放绑定 turn/revision，取消后丢弃迟到回调。麦克风和扬声器轮流使用，播放时不回收自己的语音；点击打断不是未经实测的自动语音插话。

识别输出先在页面供用户确认/修改，再进入已有脱敏校验。确认范围是非敏感演示，不录制/上传本项目音频文件；浏览器识别可能有独立服务数据流，须先落实 Q15-01。动态形象优先通过状态/声波表达，不依赖按伪音量生成嘴部动作来冒充真实数字人视频。

## 6. 持久化、费用及人工草稿

增加与原会话关联的任务记录，保存 request_id、归属、客户类型、版本、阶段、最终结果和来源；同一 request_id 幂等，服务重启将未完成任务标记中断，不自动重发付费请求。到期与会话一起清理；原会话数据保持。

新预算只有明确批准后初始化独立记录，授权日期及政策落盘；预留先于请求、失败/取消不自动退预留，不改变原 `model-budget.sqlite3`。费用信息不含问题正文或 Key。

人工辅助结果标记 draft，区分“客户自述/公开资料/未知”，可查看和修改；首轮不发送至外部坐席平台。选择实际接管时必须补队列、坐席身份/权限及回执状态合同，不能以草稿生成完成代替接管完成。
